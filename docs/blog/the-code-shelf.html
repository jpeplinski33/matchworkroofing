The Code Shelf

Two Rules Every Roof Claim Runs On. In plain words.

By MATCHWORK™ Roofing & Exteriors · October 5, 2026

One is Ohio's. One is a lab test. Neither is our opinion. Both go in the file when they apply.

Ohio's Matching Rule

Ohio Adm. Code 3901-1-54(I)(1)(b)

“When an interior or exterior loss requires replacement of an item and the replaced item does not match the quality, color or size of the item suffering the loss, the insurer shall replace as much of the item as to result in a reasonably comparable appearance.”
  1. Quality, color or size. Any one of the three can make a repair shingle a mismatch.
  2. As much of the item as it takes. The measure is the result, not the fewest shingles that cover the damage.
  3. A reasonably comparable appearance. It is judged by how the roof looks.

This is where the name MATCHWORK™ comes from. When a repair will not match, we document the mismatch and put this rule in front of your carrier, with the lab report, the match-test photos and our estimate.

Applies to policies that pay losses on a replacement cost basis. Read the full rule at codes.ohio.gov.

UL 2218, the Impact Rating

Underwriters Laboratories standard 2218

The impact class printed on a shingle comes from one test. A steel ball is dropped onto a new sample of the roofing, twice in the same spot. Then the back of the sample is checked for a crack. Bigger ball, higher drop, higher class.

  1. Passing means no crack. The sample passes a class if no hit opens a tear, split or crack in the shingle that you can see from the back.
  2. It is a new shingle on a lab bench. The test says nothing about a roof that has been in the sun for fifteen years.
  3. It does not measure granule loss. Hail can knock granules off a shingle that passes the test. The rating is about the mat cracking, not about how the roof looks afterward.

Every CertainTeed shingle we install carries a class. It is listed on that shingle's own page.

Steel balls stand in for hail. Real hail is softer, colder and comes at an angle, so the test is a comparison between products, not a promise about a storm.
